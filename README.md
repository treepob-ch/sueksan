# สืบสาน · คลังภูมิปัญญาหมอพื้นบ้าน (ต้นแบบ)

ต้นแบบแอปบันทึกและค้นหาองค์ความรู้หมอพื้นบ้านที่ได้รับการรับรอง โดยทีม **TRIVIJIT**

- เปิดใช้งาน: https://treepob-ch.github.io/sueksan/
- ฝั่งประชาชน (ทำเนียบหมอ องค์ความรู้) ใช้ได้โดยไม่ต้องเข้าสู่ระบบ
- ฝั่งเจ้าหน้าที่ใช้บัญชีทดสอบ ซึ่งแจ้งให้คณะกรรมการผ่านช่องทางของผู้จัด
- ข้อมูลทั้งหมดในแอปเป็นข้อมูลสมมุติเพื่อการสาธิต สิ่งที่ผู้ทดลองเพิ่มหรือแก้ไขจะเก็บไว้ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
- ในต้นแบบนี้ ขั้นตอน AI อ่านเอกสารสาธิตด้วยข้อมูลจำลอง (บันทึกนายยาใจ) ยังไม่ส่งเอกสารจริงให้ AI
